# Çöp Adam Savaşları

Tüm dosyalar aynı klasörde (GitHub’a klasör yüklemeden kullanılır).

## Dosyalar

| Dosya | Ne işe yarar |
|-------|----------------|
| `index.html` | Arayüz |
| `style.css` | Stiller |
| `01-core.js` | Sabitler, canvas |
| `02-units.js` | Madenci / sopalı / okçu |
| `03-draw.js` | Çizim |
| `04-gameplay.js` | Oyun döngüsü, AI |
| `05-menu-network.js` | Menü, hesap, arkadaş, co-op |
| `server.js` | Sunucu |
| `package.json` | npm bağımlılıkları |
| `data/users.json` | Kullanıcı kayıtları (sunucu) |

## Çalıştırma

```bash
npm install
npm start
```

http://localhost:3847

## Render / GitHub

Bu listedeki dosyaları **aynı repo köküne** yükle. Alt klasör gerekmez (`data` hariç; yoksa sunucu oluşturur).
